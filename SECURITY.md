# Security policy

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/qqn2/waves-gui/security/advisories/new). If that route is unavailable, contact the repository owner through their GitHub profile and ask for a private reporting channel before sharing details.

Do not attach confidential diagrams, proprietary signal names, credentials, internal URLs, or unredacted screenshots to public issues. A minimal synthetic reproduction is preferred.

Only the current `master` branch is supported. The project is a client-only static application; reports claiming a server-side or account-security impact should explain the actual deployment context.
